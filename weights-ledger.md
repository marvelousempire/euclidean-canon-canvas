# Weights Ledger Mapping

> **Intent block:** Connect the Euclidean canon mask to the contractor's conscience 64-weight pay fractal so every activated node earns a weight and every docked node drops one. Expected outcome: the audit sheet is also a score — the aces hear dissonance before they read a missed mark.

## The fractal

The job is 100%. Fractal it into 64ths. One 64th is the smallest markable unit — one brick. Each brick earns one weight. Sixty-four weights is the full purse.

| 64ths | Unit | Bubble size (stack-that) |
|-------|------|------------------------|
| 1 | Cell / brick | XS |
| 4 | Micro-slice | S |
| 16 | Cassette | M |
| 64 | Planet / full job | 3X large |

## How the mask earns weights

Walk the Björklund mask. Every 1 activates a node and assigns the next weight from the color sequence. Every 0 rests — no weight, no note.

The color sequence is the ordered list of node values or MIDI notes. When talea length and color length differ, the same rhythm falls on different nodes each cycle — isorhythm. The ledger records which node earned which weight on which cycle.

## Deductions

- Missed brick: minus one weight.
- Slow gate (telemetry from Monitor That): minus one weight.
- Failed gate: minus one weight per failure.
- The deduction is computed, not negotiated. The conscience marks.

## Audible proof

Each activated node emits its weight as a MIDI note in the C0–A8 range RomThat defined. A full purse rings clean. A docked purse is a missing note. The aces hear the harmony or dissonance of every actor's sheet.

## Contract That binding

Every actor is a party to this structure at birth. The actor profile carries the weights contract as a tentacle. When the actor joins any build, the contract is already in force. Monitor That measures. The aces audit. The conscience does not argue.
