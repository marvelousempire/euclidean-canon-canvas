# Euclidean Canon Canvas

Visual canvas and doctrine for Euclidean rhythms, Björklund algorithm, nine-node CCK mapping, and rhythmic canons under Morph Law.

## What this is

One three-number seed. One deterministic function. One binary mask. Nine nodes. Multiple phase-offset voices. One audible and visual result.

## Seed

`pulses`, `steps`, `rotation`

## Algorithm

Björklund (bucket method for speed, full Björklund for exact necklaces).

## Mapping

Binary mask → nine-node circle activation.  
Active nodes receive the next weight from the color sequence and emit as MIDI note.

## Canon

Second (and further) voices run the same talea at different rotations. Mosaic tilings produce no collisions.
